## Standard: 회원가입 → 로그인 → 401/200 → 평점 → 즐겨찾기
$ POST /members  body={"email": "w10.1037f9@example.com", "password": "***", "nickname": "w101037f9"}
→ 201 {"isSuccess": true, "code": "COMMON201", "message": "회원가입에 성공했습니다.", "result": {"memberId": 1, "email": "w10.1037f9@example.com", "nickname": "w101037f9"}}

$ POST /auth/login  body={"email": "w10.1037f9@example.com", "password": "***"}
→ 200 {"isSuccess": true, "code": "COMMON200", "message": "로그인에 성공했습니다.", "result": {"nickname": "w101037f9", "accessToken": "***"}}

$ GET /members/me
→ 401 {"isSuccess": false, "code": "AUTH401_2", "message": "로그인이 필요한 요청입니다.", "result": null}

→ 200  Access-Control-Allow-Origin: http://localhost:5173

$ OPTIONS /favorites  Origin: http://evil.example
